# 改进 AI Dev System 提示词

```text
请帮我改进这套 AI Dev System。

先阅读：
- AGENTS.md
- docs/evolution-rules.md
- docs/maintenance-checklist.md
- README.md

要求：
1. 先判断我的新增需求属于规则、prompt、checklist、脚本还是项目私有配置。
2. 不要把一次性问题写进通用模板。
3. 不要让 AGENTS.md 变得臃肿。
4. 如果能自动检查，优先建议脚本。
5. 修改后运行 scripts/audit-ai-dev-system.ps1。

输出：
- 改了哪些文件
- 为什么这样放
- 是否增加了系统复杂度
- 后续维护建议
```
