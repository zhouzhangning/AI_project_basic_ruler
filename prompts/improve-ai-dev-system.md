# 改进 AI Dev System 提示词

```text
请帮我改进这套 AI Dev System。

先阅读：
- AGENTS.md
- docs/evolution-rules.md
- docs/maintenance-checklist.md
- README.md

要求：
1. 先判断我的新增需求属于规则、prompt、checklist、脚本还是项目私有配置。
2. 不要把一次性问题写进通用模板。
3. 不要让 AGENTS.md 变得臃肿。
4. 如果能自动检查，优先建议脚本。
5. 如果你认为某条经验应该加入系统，先输出候选经验，等待我审核确认后再写入。
6. 未经我确认，不要擅自添加经验、规则、禁区或流程到通用系统。
7. 修改后运行 scripts/audit-ai-dev-system.ps1。

输出：
- 改了哪些文件
- 为什么这样放
- 哪些内容是经过审核后加入的经验
- 是否增加了系统复杂度
- 后续维护建议
```
