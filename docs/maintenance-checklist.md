# 维护检查清单

建议每月或每完成 3 个项目后执行一次。

## 结构检查

- [ ] `AGENTS.md` 是否仍然简短、清晰、可执行。
- [ ] `ai-approval-rules.md` 是否覆盖最新高风险动作。
- [ ] `prompts/` 中是否有重复模板。
- [ ] `docs/project-memory.md` 是否有过时经验。
- [ ] `docs/ai-work-log.md` 是否需要归档。
- [ ] `README.md` 是否准确描述当前文件结构。

## 规则质量检查

- [ ] 每条规则是否能说明防止什么错误。
- [ ] 是否存在项目专属规则混入通用模板。
- [ ] 是否有重复、冲突或含糊的规则。
- [ ] 是否有过长规则应拆成 checklist 或 prompt。
- [ ] 是否有规则可以改成脚本自动检查。

## 脚本检查

- [ ] `init-ai-dev-system.ps1` 能复制完整模板。
- [ ] `audit-ai-dev-system.ps1` 能正常运行。
- [ ] 脚本不执行破坏性动作。
- [ ] 脚本默认不覆盖用户文件。

## Git 检查

- [ ] 本地工作区干净。
- [ ] 重要变更已提交。
- [ ] 已推送远端。
- [ ] commit message 能说明为什么升级。
