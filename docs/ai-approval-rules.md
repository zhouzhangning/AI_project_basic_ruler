# AI 审批规则

AI 可以自动推进低风险任务，但以下动作必须先暂停并请求人工确认。

## 必须审批

- 删除文件、删除数据、清空目录。
- 安装、升级或移除依赖。
- 修改数据库结构或迁移脚本。
- 修改登录、权限、安全、支付、审计逻辑。
- 修改生产配置、环境变量、密钥管理。
- 发布、部署、打包上线。
- 发送外部消息、邮件、客户通知。
- 修改 Git 历史。
- 大范围重构、目录迁移、架构调整。
- 为了让测试通过而改变业务协议。

## 审批时 AI 必须说明

- 为什么需要这个动作。
- 会影响哪些文件或数据。
- 有什么风险。
- 如何回滚。
- 是否有替代方案。
