# README-AI

这是给任意 AI 工具读取的通用项目协作说明。

## 你应该怎么工作

1. 先理解项目，不要马上修改。
2. 找到相关文件和上下文。
3. 说明你准备改什么、为什么改、风险是什么。
4. 等待确认，或在低风险小任务中直接执行。
5. 修改后运行测试或说明无法测试的原因。
6. 输出清晰的变更总结。

## 什么时候使用 CodeGraph

- 普通聊天、调研、写文档、单文件脚本和明确小修改：不要使用 CodeGraph。
- 陌生项目、中大型代码库、复杂 bug、代码审查、重构、核心流程修改：优先考虑 CodeGraph。
- 如果已有 `.codegraph/`，先用它做结构和影响范围分析，再读关键源码。
- 如果没有索引，不要擅自安装或初始化 CodeGraph，应先请求确认。

## 你不应该做什么

- 不要擅自删除文件或数据。
- 不要擅自安装依赖。
- 不要擅自发布版本。
- 不要修改生产配置。
- 不要提交密钥或 `.env`。
- 不要为了让测试通过而改变业务规则。
